# Knowledge

An Open Knowledge Format bundle: one markdown note per person, project, event, place, preference or topic,
linked with ordinary markdown links. `log.md` records every change.

- `people/`: people in the user's life
- `projects/`: things the user is working on
- `events/`: plans, appointments, deadlines
- `places/`: places that matter
- `preferences/`: how the user likes things done
- `topics/`: everything else worth knowing
